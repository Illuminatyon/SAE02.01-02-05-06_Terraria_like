To complete the implementation of the furnace as a placeable block:

1. Copy the furnace.png image from the items directory (src\main\resources\fr\iut\hev\root\img\items\furnace.png) to this directory (src\main\resources\fr\iut\hev\root\img\tile\furnace.png)
2. The image should be the same size as other tile images in this directory (typically 32x32 pixels)
3. If necessary, resize or modify the image to fit the tile grid

This is needed for the furnace to display properly when placed as a block in the game world.
